# History Teller — контракт на риг-арт персонажей

Это спецификация для художника или AI-генерации. Если части нарисованы по этим
правилам, они без доработок встают в кукольный риг движка (`CharacterRig.cs`) и
оживают в анимациях взаимодействия (очарование, поцелуй, заговор, перенос и т.д.).

Стиль-референс — Storyteller: маленькие милые «чиби»-фигурки в полный рост, мягкие
тёплые цвета, толстый тёмно-коричневый контур (#2b2419), бумажная палитра.

---

## 1. Формат файла

- **Один персонаж = набор PNG-слоёв**, каждый слой — отдельный файл.
- **Размер кадра: 512 × 512 px**, одинаковый у всех слоёв персонажа.
- **Прозрачный фон** (alpha). Никаких подложек/рамок.
- Все слои нарисованы в **одной системе координат**: если их просто наложить
  друг на друга в порядке z, получается цельный персонаж в нейтральной позе.
- Персонаж занимает примерно центральные 60–70% кадра; **ступни у отметки
  y ≈ 470** (низ), макушка — y ≈ 60. Слева/справа поля для замаха рук.

## 2. Слои (обязательные), порядок отрисовки сзади→вперёд

| z | имя слоя     | что входит                                   |
|---|--------------|----------------------------------------------|
| 0 | `back_arm`   | дальняя рука целиком (плечо→кисть)            |
| 1 | `body`       | торс, ноги, одежда, шея (без головы и рук)    |
| 2 | `front_arm`  | ближняя рука целиком (плечо→кисть)            |
| 3 | `head`       | голова: лицо, волосы, убор/корона, уши        |

Опционально:

| z | имя слоя | что входит                                        |
|---|----------|---------------------------------------------------|
| 4 | `prop`   | предмет в руке (кубок, кинжал, мешок) — поверх всего |

Руки рисуются **в нейтральном положении вдоль тела**. Анимация будет вращать их
вокруг плеча — поэтому рука должна быть цельной и «висеть» из точки плеча.

## 3. Пивоты (точки вращения) — самое важное

Для каждого слоя указывается **пивот** — точка, вокруг которой движок его вращает.
Координаты нормализованные: `(0,0)` — левый-верх кадра, `(1,1)` — правый-низ.

Рекомендованные пивоты (художник может сдвинуть под конкретного персонажа, но
тогда обязательно прописать фактические в манифесте):

| слой        | пивот (x, y) | смысл точки           |
|-------------|--------------|-----------------------|
| `head`      | 0.50, 0.34   | основание шеи         |
| `front_arm` | 0.60, 0.30   | ближнее плечо         |
| `back_arm`  | 0.40, 0.30   | дальнее плечо         |
| `body`      | 0.50, 0.78   | бёдра (наклон корпуса)|
| `prop`      | по кисти     | центр хвата           |

Чтобы пивоты было легко снять: держите плечи на одной высоте (≈ y 0.30) и шею по
центру (x 0.50). Тогда стандартные пивоты подойдут почти без правок.

## 4. Нейминг и раскладка файлов

```
Art/src/rig/<charId>/back_arm.svg   (исходник, вектор — по желанию)
Art/src/rig/<charId>/body.svg
Art/src/rig/<charId>/front_arm.svg
Art/src/rig/<charId>/head.svg

UnityProject/Assets/Resources/Art/rig/<charId>/back_arm.png   (то, что грузит игра)
UnityProject/Assets/Resources/Art/rig/<charId>/body.png
UnityProject/Assets/Resources/Art/rig/<charId>/front_arm.png
UnityProject/Assets/Resources/Art/rig/<charId>/head.png
UnityProject/Assets/Resources/Art/rig/<charId>/rig.json
```

`<charId>` — это id из `characters.json` (`cleopatra`, `caesar`, `apollodorus`, …).

## 5. Манифест `rig.json` (рядом со слоями персонажа)

```json
{
  "id": "cleopatra",
  "frame": 512,
  "parts": [
    { "name": "back_arm",  "z": 0, "pivot": [0.40, 0.30] },
    { "name": "body",      "z": 1, "pivot": [0.50, 0.78] },
    { "name": "front_arm", "z": 2, "pivot": [0.60, 0.30] },
    { "name": "head",      "z": 3, "pivot": [0.50, 0.34] }
  ]
}
```

Если у персонажа нет какого-то слоя (например, безрукий силуэт) — просто не
указывайте его в `parts`, движок это переживёт.

## 6. Что движок умеет делать с этими частями

Имея слои и пивоты, `CharacterRig` проигрывает анимации, вращая/смещая части:

- **idle** — лёгкое «дыхание»: корпус и голова чуть качаются.
- **leanToward(other)** — наклон корпуса и головы к собеседнику.
- **raiseArm / reach** — поднять ближнюю руку (потянуться, поднести предмет).
- **headTilt, nod, shake** — наклон/кивок/мотание головой.
- **bounceIn** — выезд/появление в кадре.

Из них собираются сцены-взаимодействия, например «очарование»:
Клеопатра leanToward(Цезарь) + headTilt, Цезарь nod, между ними всплывают
сердечки. Каждой паре «правило сцены → анимация» соответствует свой клип.

## 7. Шаблон промпта для AI-генерации (если рисуете через Midjourney/SD)

> chibi character, full body, **<персонаж: e.g. Cleopatra, Egyptian queen, black
> bob haircut, gold diadem with cobra, turquoise collar>**, cute storybook style,
> thick dark brown outline, warm parchment palette, flat shading, front view,
> standing neutral pose arms at sides, **transparent background**, centered, feet
> near bottom — game sprite

Затем в редакторе (Photoshop/Procreate) разнести на 4 слоя (back_arm / body /
front_arm / head), каждый экспортировать как отдельный PNG 512×512 с прозрачностью
в одной системе координат. Снять пивоты плеч/шеи/бёдер → вписать в `rig.json`.

## 8. Чек-лист приёмки одного персонажа

- [ ] 4 PNG (back_arm, body, front_arm, head), 512×512, прозрачные.
- [ ] При наложении в порядке z получается цельная нейтральная фигура.
- [ ] Руки цельные, «висят» из плеч; плечи на одной высоте.
- [ ] `rig.json` с фактическими пивотами.
- [ ] Контур и палитра совпадают со стилем остальных персонажей.

Эталон — папка `cleopatra/` (сделана движком как образец): можно открыть слои и
повторить раскладку для остальных героев.
