# Ресурсы контента

Пусто намеренно: весь контент (JSON, арт, звук) живёт в облаке и приезжает через `ContentSync`.
Источник правды — `Content/` в корне репозитория; публикация — `python3 tools/publish_content.py`.

Загрузчики (`ArtStore`, `RomeContent`, `L10n`, `Audio`) умеют откатываться на файлы из этого
каталога, если они здесь появятся, — так работает вариант «вшить стартовую главу в установку».
