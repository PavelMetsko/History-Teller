# Запуск History Teller на iPhone

Unity-проект уже собран: папка **`UnityProject/`**. Создавать проект и копировать файлы не нужно.

## 1. Открыть проект (один раз)

1. Unity Hub → **Add** (или Open) → **Add project from disk** → выбрать папку `UnityProject`.
2. Если Hub скажет, что версия проекта (2022.3.45f1) не совпадает с установленной —
   просто выбрать вашу установленную версию и подтвердить (Continue / Upgrade). Это нормально.
3. Первое открытие займёт пару минут (Unity скачает пакеты из manifest.json, включая Newtonsoft).

Важно: для сборки на телефон у установленной версии Unity должен стоять модуль
**iOS Build Support** (Unity Hub → Installs → ⚙ у вашей версии → Add modules).

## 2. Проверить в редакторе

Нажать **Play** — игра запустится сразу (UI строится из кода, сцена не нужна).

Тесты движка: Window → General → **Test Runner** → EditMode → Run All.

## 3. Собрать на iPhone

1. В меню Unity: **HistoryTeller → Build iOS (Xcode project)**.
   Скрипт сам создаст сцену, применит настройки (portrait, bundle id `com.pavel.historyteller`),
   переключит платформу и соберёт Xcode-проект в папку `ios-build/` (откроется в Finder).
2. Открыть `ios-build/Unity-iPhone.xcodeproj` в Xcode:
   - Targets → **Unity-iPhone** → Signing & Capabilities → ✅ Automatically manage signing →
     Team: ваш Apple ID (бесплатного Personal Team достаточно);
   - подключить iPhone кабелем → выбрать его сверху как destination → **Run (⌘R)**.
3. Первый запуск: на телефоне Настройки → Основные → VPN и управление устройством →
   доверять профилю разработчика. (С бесплатным аккаунтом приложение живёт 7 дней, потом пересобрать.)

Повторные сборки после правок: снова HistoryTeller → Build iOS — скрипт пересоберёт в ту же
папку, настройки подписи в Xcode сохранятся.

## 4. Обновление контента

Источник истины — `Content/` в корне репозитория. После правок:

```bash
python3 tools/simulate.py Content/rome --all          # валидация
cp -r Content UnityProject/Assets/Resources/           # синхронизация в Unity
```

(Позже заменим на Addressables — контент будет обновляться без пересборки приложения.)

## Известные ограничения прототипа

- Арт — цветные плитки с инициалами (эмодзи в стандартном шрифте Unity не рендерятся).
  Этап «шлифовка UI»: TextMeshPro, спрайты, анимации, звук.
- Управление tap-based (как в HTML-прототипе); drag&drop — этап шлифовки.
- iPad: Canvas масштабируется автоматически, но раскладку под планшет стоит довести отдельно.
