# Патч 4.0 — free-to-play + мета удержания

Один релиз iOS + Android. Источник правды для обеих платформ: константы, ключи хранения,
тексты (`ui.*` в `Content/i18n`) и поведение должны совпадать.

## 0. Почему

Данные админки (630 игроков, 20.10–06.11.2026): до 2-го эпизода платной главы доходят 1–4%,
роликов «уровень за рекламу» — 37 на ~400 упёршихся; D1 6–13%; 88% играют один день; покупок 0.

## 1. Монетизация

### Главы
Все главы бесплатны **в клиенте 4.0** (без флага `free` в манифесте — старые клиенты 3.x
сохраняют свою модель, пока не обновятся). Окно покупки главы и «уровень за ролик» удаляются.
Линейное открытие уровней внутри главы остаётся (`ProgressStore.isUnlocked`).

### Интерстишел (AdMob)
Показ — при уходе с экрана награды (кнопки «Следующий эпизод» / «К карте»), если всё верно:
- реклама не отключена покупкой (`adsFree(глава уровня)`);
- `ads.interstitial` в манифесте не `false` (по умолчанию включено);
- игрок решил за всю жизнь ≥ `ads.interAfter` эпизодов (по умолчанию **3**);
- с последнего интерстишела пройдено ≥ `ads.interEvery` эпизодов (по умолчанию **2**);
- с последней полноэкранной рекламы (интер или ревард) прошло ≥ `ads.interGapSec` (по умолчанию **60** с).
Счётчик `ht.meta.sinceInter` растёт на каждое завершение уровня (и повторное), обнуляется показом.
Не загрузился — просто идём дальше, без ожидания. Блоки: см. §8.

### Подсказка (ревард)
Кнопка 💡 на доске уровня (рядом с ℹ︎ и ↺), с бейджем числа подсказок (∞ в купленной главе).
Есть только у уровней с `solution`.
- Есть подсказки (или глава куплена) → тратим 1 (в купленной главе — бесплатно) и применяем.
- Нет подсказок → окно «Подсказки закончились»: [▶ Смотреть ролик] (+1 и сразу применить),
  [👑 Без рекламы] (окно покупки главы), [Отмена]. Ролик не загружен → кнопка неактивна с текстом «Ролик загружается…».

Применение: найти первый индекс `i` по порядку эталона, где панель ≠ `solution[i]`
(сцена и список персонажей с порядком). Поставить `panels[i] = solution[i]`; если та же сцена стоит
в другой панели `j` — очистить `j`. Подсвеченная панель: золотое сияние ~1.2 с. Если всё уже совпадает
(доска верна) — ничего не тратим.
Уровень с использованной подсказкой запоминается (`ht.meta.hinted`) — без бонуса «без подсказок».

Стартовый запас: **3** подсказки (одноразово при первом запуске 4.0, `ht.meta.init`).

### Покупка главы («Глава без рекламы»)
Общей покупки нет (решение 06.11). Каждая глава продаётся отдельно, как до 4.0
(`com.decima.historyteller.chapter.<epoch>`, у Рима продукта нет). `adsFree(epoch)` = купленная глава
**или** старая подписка (больше не продаётся, действующая работает везде). В купленной главе: нет
интерстишелов и безлимит подсказок (бейдж ∞). Возврат серии без ролика — только у подписчиков.
Окно главы: «Глава без рекламы», название главы, `ui.chapter_noads_b1/b2`, `ui.premium_b3`, кнопка
`ui.chapter_noads_cta` с ценой (нет цены — нет кнопки), «Восстановить», условия/приватность. Входы:
плашка 👑 «Убрать рекламу — цена» в шапке карты главы (если не куплена и есть цена), окно «Подсказки
закончились» (глава текущего уровня). Короны в меню и строки в настройках нет.

## 2. Мета-прогресс

Все ключи — `UserDefaults` (iOS) / `SharedPreferences "ht"` (Android) с префиксом `ht.meta.`.
«День» = локальный календарный день: `floor((unixSec + tzOffsetSec) / 86400)`.

| ключ | тип | смысл |
|---|---|---|
| `ht.meta.init` | bool | стартовые подсказки и миграция XP выданы |
| `ht.meta.xp` | int | опыт |
| `ht.meta.hints` | int | подсказки |
| `ht.meta.hinted` | set<string> | уровни, где брали подсказку |
| `ht.meta.streak` | int | серия дней с решённым эпизодом |
| `ht.meta.streakDay` | int | день последнего решения |
| `ht.meta.bestStreak` | int | рекорд |
| `ht.meta.giftDay` | int | день последнего подарка |
| `ht.meta.giftStep` | int | шаг календаря подарков 1…7 |
| `ht.meta.dailyDone` | int | день, когда решён эпизод дня |
| `ht.meta.sinceInter` | int | эпизодов с последнего интерстишела |
| `ht.meta.lastFullscreen` | double | unix-сек последней полноэкранной рекламы |
| `ht.meta.restoredFor` | int | день, за который уже восстанавливали серию |
| `ht.meta.pushAsked` | bool | системное разрешение на уведомления уже спрашивали |
| `ht.meta.lastLevel` | string | последний открытый уровень (для пушей) |

### Опыт
Первое решение уровня: **100 XP** + **50** если без подсказки. Эпизод дня — ×2.
Повторное решение — 0. Миграция при `init`: `xp = solvedCount × 100`.

### Звания (уровни игрока)
Порог уровня n (n ≥ 1): `T(1) = 0`, `T(n+1) = T(n) + 150 + 50·n`
(200, 450, 750, 1100, 1500, …; 20-й ≈ 12 350 XP ≈ 100 эпизодов).
Имя: `ui.rank.<min(n,15)>`. Повышение — **+2 подсказки** за каждый новый уровень.

### Серия (streak)
При первом решении за день: если `streakDay == today-1` → `streak+1`; если `streakDay == today` → без
изменений; иначе → `streak = 1`. `bestStreak = max`.
Вехи (выдаются при достижении): 3 → +1 подсказка, 7 → +3, 14 → +5, 30 → +10, далее каждые 30 → +10.
**Восстановление:** если `streakDay == today-2`, `streak ≥ 2`, `restoredFor != today` — в меню
плашка «Серия N дней прервалась» → [▶ Вернуть за ролик] (подписчики — без ролика) → `streakDay = today-1`,
`restoredFor = today`.
Отображаемая серия: `streak`, если `streakDay ≥ today-1`, иначе 0 (или «прервалась» по правилу выше).

### Ежедневный подарок
При открытии меню, если `giftDay != today`: окно с календарём на 7 дней.
`giftStep = (giftDay == today-1) ? giftStep % 7 + 1 : 1`. Награда по шагу: `[1,1,2,1,2,2,3]` подсказок.
Кнопка «Забрать» → `giftDay = today`. Первый запуск после онбординга — подарок тоже показывается.

### Эпизод дня
Кандидаты: по главам в порядке манифеста — первые **10** уровней каждой главы, кроме выключенных и
пройденных; если пусто — все первые 10. Индекс: `(today × 2654435761) mod 2^32 mod count`.
Карточка в меню: обложка главы, «Эпизод дня», название уровня (`level.<id>.title`), глава, «×2 XP +1 💡».
Решён сегодня — плашка «Готово ✓, новый завтра». Открытие обходит линейный замок главы.
Награда: XP×2 и +1 подсказка (один раз за день, `dailyDone = today`).

### Экран награды (после первого решения)
Порядок: решил → «Дальше» → карточка факта → «Дальше» → **экран награды**:
1. «+150 XP» со счётчиком, полоса уровня заполняется (с переходом через порог, если повышение).
2. Повышение: вспышка, «Новое звание: <имя>», «+2 💡».
3. Карточка эпизода «переворачивается» (обложка уровня) + «Добавлена в альбом» + кольцо главы «12 / 71».
4. Серия: 🔥 N (подпрыгивает, если выросла сегодня) + веха «+3 💡», если достигнута.
5. Эпизод дня: «Эпизод дня ×2».
6. Глава пройдена целиком: золотая печать «Знаток: <глава>».
Кнопки: **«Следующий эпизод ▶»** (если есть следующий в главе) и «К карте». Повторное решение —
без экрана награды (как раньше: на карту).

### Альбом
Кнопка в меню. Вкладки-главы (порядок манифеста) с «N / M». Сетка карточек: решённые — обложка уровня
и название, нерешённые — тёмная карточка с номером и «?». Тап по решённой — факт (`level.<id>.fact`,
`level.<id>.source`). Полностью собранная глава — золотая печать на вкладке.

### Меню
Сверху полоса: эмблема уровня + «Ур. N · Звание» + полоса XP; 🔥 серия; 💡 подсказки. Короны нет.
Кнопки: «Играть», «Альбом». Справа — карточка эпизода дня (вместо героев на узких экранах).

## 3. Уведомления (локальные)
Системное разрешение спрашиваем один раз — после закрытия первого экрана награды.
Перепланирование при уходе в фон и после каждого решения: снять все наши, поставить:
- `streak` — если серия ≥ 1 и сегодня ещё не решал: сегодня 20:00 (если в будущем) — `ui.push.streak` («🔥 Серия %d дн. сгорит в полночь»).
- `daily` — завтра 19:00 — `ui.push.daily` с названием эпизода дня завтрашнего дня.
- `comeback` — через 3 дня 18:00 — `ui.push.gift` («Тебя ждёт подарок 🎁»).
- `week` — через 7 дней 18:00 — `ui.push.week` («История ждёт: «%@»» — последний/следующий эпизод).
Заголовок всех — `History Teller`.

## 4. Телеметрия (новые типы)
`hint_use`, `hint_ad`, `inter_show`, `daily_open`, `daily_done`, `gift_claim`, `streak_restore`,
`rank_up`, `premium_open`, `purchase`. Поля level/chapter где уместно. Сервер принимает их и
показывает в админке (вкладка «Реклама»).

## 5. Манифест
`ads`: `rewarded` (bool, ролики вообще), `cooldownSec`, **новые** `interstitial` (bool),
`interAfter`, `interEvery`, `interGapSec` (int). Все необязательные.

## 6. Тексты
Все новые строки — `ui.*` в `Content/i18n/*.json` (9 языков), публикуются в облако до релиза
(старым клиентам не мешают).

## 7. Что удаляется
`RewardedUnlocks`, окно покупки главы (PaywallView/PaywallScreen в старом виде), цены на карточках
глав, «первый эпизод бесплатно».

## 8. AdMob
Interstitial iOS / Android — создать блоки в AdMob (те же приложения). Debug — тестовые блоки Google:
iOS `ca-app-pub-3940256099942544/4411468910`, Android `ca-app-pub-3940256099942544/1033173712`.

## 9. «Путь огня» (серия как эволюция пламени)
Стадии пламени по текущей серии (`Meta.flameTiers`): 1 день — Искра (+0%), 3 — Свеча (+10% XP),
7 — Факел (+20%), 14 — Костёр (+30%), 30 — Маяк (+40%), 60 — Вечный огонь (+50%). Имена `ui.flame.1…6`.
Бонус умножает опыт первого решения (после ×2 эпизода дня): `gain += gain * bonus / 100`.
Вехи подсказок (`Meta.milestones`): 3→1, 7→3, 14→5, 30→10, 60→10, 100→15, 150→10, 200→10, 365→30,
после года +10 каждые 30 дней.
Пламя (FlameBadge) растёт и меняет цвет со стадией (оранжевый → красный → синий → фиолетовый),
с Костра — ореол, с Маяка — искры по кругу. В меню чип пламени ведёт на экран «Путь огня»: слева
текущее пламя, стадия, «Серия: N», бонус, «До «Факел» — N дн.», рекорд, статус дня (`ui.flame_today` /
`ui.flame_todo`) или «Вернуть серию»; справа — горизонтальная дорога станций (начала стадий + вехи),
пройденные золотые, следующая пульсирует, на отрезке — маркер-огонёк. На экране награды пламя вместо
огонька, бонус «+N% опыта» и плашка «Пламя разгорается! <стадия>» при переходе на новую стадию.
