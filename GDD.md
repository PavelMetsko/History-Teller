# Концепт-документ: «History Teller» (рабочее название)

Narrative-puzzle для iOS/Android (телефон + планшет), вдохновлённая Storyteller, но на реальных исторических сюжетах. Unity.

---

## 1. Elevator pitch

Игрок собирает комикс из панелей: расставляет исторических персонажей и сцены так, чтобы получилась история, соответствующая заголовку уровня («Убийство Цезаря», «Клеопатра очаровывает Рим», «Сто дней Наполеона»). В отличие от Storyteller, каждая решённая головоломка — реальное историческое событие, и после решения игрок получает короткую историческую справку «как это было на самом деле».

**Жанр:** puzzle / narrative. **Сессия:** 2–5 мин на уровень. **Аудитория:** casual-игроки 18–45, любители истории, фанаты Storyteller/Gorogoa/What Remains. Образовательный уклон — плюс для фичеринга в App Store и для школьного/семейного сегмента.

**Ключевое отличие от Storyteller:** не выдуманные сказочные сюжеты, а история; уровни сгруппированы в «эпохи» (Рим, Египет, Наполеоника, …); после каждого уровня — фактическая справка с разделением «факт / легенда».

> Юридическая заметка: игровые механики авторским правом не защищаются — копировать арт, персонажей, тексты и название Storyteller нельзя. Свой арт-стиль обязателен.

## 2. Core loop

1. Игрок открывает уровень: заголовок («Брут предаёт Цезаря») + пустая сетка панелей (2–6) + набор «сцен» (фонов) и «персонажей».
2. Перетаскивает сцену в панель → панель получает контекст (Сенат, дворец, поле боя).
3. Перетаскивает персонажей в панель → движок симулирует: персонажи реагируют на сцену, друг на друга и на состояние из предыдущих панелей (жив/мёртв, влюблён, предатель, коронован…).
4. Если итоговая последовательность состояний удовлетворяет цели уровня — победа, анимация, историческая справка.
5. Доп. цели («корона»): решить уровень альтернативным способом / собрать «легендарную» версию событий (например, «Наполеон низкорослый» — миф) — справка объясняет, почему это миф.

### Механика состояния (как в Storyteller)
Симуляция идёт слева направо, панель за панелью. Каждая панель = (Сцена, Персонажи[]) → правила движка изменяют состояние мира (флаги на персонажах). Цель уровня = предикат над финальным (или промежуточным) состоянием.

Пример «Убийство Цезаря» (3 панели):
- П1: Сцена «Форум» + Цезарь + Брут → флаг `allies(Цезарь, Брут)`
- П2: Сцена «Заговор» + Брут + Кассий → флаг `plotting(Брут)`
- П3: Сцена «Сенат» + Цезарь + Брут → правило: `plotting(X) + ally(X,Y) в сцене Сенат → kills(X,Y)` → Цезарь мёртв, Брут предатель. Цель достигнута.

## 3. Контент-система (требование №2: лёгкое добавление контента)

Главный принцип: **движок не знает ничего про Цезаря.** Весь контент — данные. Программист нужен только для новых *типов правил*, а не для новых уровней.

### 3.1 Сущности (все — данные, JSON/ScriptableObject)

| Сущность | Поля |
|---|---|
| **Character** | id, имя, спрайты по состояниям (idle, dead, in_love, angry, crowned…), теги (ruler, soldier, lover…) |
| **Scene** | id, фон, slots (сколько персонажей помещается), теги (public, private, battle, throne…) |
| **Rule (шаблон!)** | trigger: (теги сцены, теги/флаги персонажей) → effect: (установить/снять флаги, анимация). Пример: `scene:battle + A:flag(armed) + B:flag(enemy_of_A) → B:dead` |
| **Level** | id, заголовок, эпоха, сетка, доступные сцены/персонажи, goal-предикат, текст исторической справки, alt-goals |
| **Goal-предикат** | дерево условий: `dead(caesar) AND betrayed_by(caesar, brutus)` |

### 3.2 Почему это «дженерик-шаблоны»
- Правила — параметризованы тегами, а не конкретными персонажами: правило «ревность» (`A loves B + B loves C → A jealous_of C`) одно, работает и для Клеопатры/Цезаря/Антония, и для Жозефины/Наполеона.
- Новый уровень = новый JSON + спрайты. Новая эпоха = пак персонажей/сцен + уровни. Без перекомпиляции.
- Контент доставляется через **Unity Addressables** с CDN → новые эпохи выходят без обновления приложения (важно и для монетизации, и для скорости итераций).

### 3.3 Редактор уровней
Внутренний Unity-редактор (EditorWindow или отдельная сцена): собрать уровень, прогнать симуляцию, проверить решаемость (brute-force всех расстановок — пространство маленькое, это реально). Позже его же можно превратить в пользовательский UGC-редактор (см. монетизацию).

### 3.4 Историческая достоверность
- На уровень: 1–3 абзаца справки + источник + плашка «факт / упрощение / легенда».
- Это контент-фича и маркетинговый крючок («выучи историю, играя»), и защита от критики историков.

## 4. Архитектура (Unity, iOS-разработчику будет комфортно)

- **Unity 2022 LTS+ / Unity 6**, 2D, UI Toolkit или uGUI; один проект → iOS + Android, адаптивная вёрстка под планшет (та же сетка, крупнее панели).
- Слои:
  - `Simulation` — чистый C# без UnityEngine: мир-состояние, движок правил, проверка целей. Юнит-тестируемый, переиспользуется в редакторе/солвере.
  - `Content` — загрузка JSON/Addressables, валидация.
  - `Presentation` — drag&drop, анимации, спрайты по флагам.
  - `Meta` — прогресс, IAP, аналитика.
- Сейвы: локально + iCloud/Google Play Saves.
- Аналитика: Unity Analytics или Firebase (где застревают, где дропаются — критично для пазлов).

## 5. Монетизация (требование №3)

Как монетизируется референс: Storyteller на ПК/Switch — премиум ($14.99), на мобильных вышел **эксклюзивом Netflix Games** — без рекламы и IAP, доступ по подписке Netflix ([Netflix](https://www.netflix.com/games/81569948), [Wikipedia](https://en.wikipedia.org/wiki/Storyteller_(video_game))). То есть прямого F2P-референса нет — ниша открыта.

Для puzzle-жанра в 2025–26 норма — гибрид IAP + реклама (~50/50, rewarded-форматы вовлекают лучше всего; ARPDAU пазлов ≈ $0.08) ([Audiencelab](https://audiencelab.ai/blog/mobile-game-monetization-strategies), [CAS.AI](https://cas.ai/2025/10/09/hybrid-monetization-mobile-games-guide-2/)).

### Рекомендация: F2P + гибрид, «мягкий» как у Storyteller-аудитории
1. **Бесплатно:** первая эпоха (Рим, ~15–20 уровней) — полноценная, без пейволла в середине главы.
2. **IAP-эпохи:** «Египет», «Наполеоника», «Средневековье» — по $2.99–3.99, либо **«Полная игра + все будущие эпохи» за $9.99–12.99** (любимый формат премиум-аудитории: «убрать всё, дай всю игру»).
3. **Rewarded-подсказки:** застрял → посмотри ролик и получи подсказку (подсветить правильную сцену для панели). Альтернатива — IAP-пак подсказок. Никаких interstitial между уровнями для купивших что-либо.
4. Позже: **подписка** ($1.99/мес) — ежедневная головоломка «в этот день в истории» + ранний доступ к эпохам.

Почему так: аудитория Storyteller-лайков ненавидит агрессивный F2P; образовательный флёр усиливает готовность платить «за хорошее». Гибрид же страхует: rewarded-подсказки монетизируют неплатящих без ущерба репутации.

### Альтернативы (зафиксировать, но не делать сейчас)
- **Чистый премиум $4.99** — просто, но мобильный премиум почти не продаётся без бренда.
- **Сделка с подписочной платформой** (Netflix Games, Apple Arcade, Play Pass): фиксированная выплата + маркетинг. Реалистично *после* того, как есть полированная демо-версия; образовательный угол — сильный питч для Apple Arcade.
- **B2B/образование:** лицензирование школам — отдельный трек, не для MVP.

## 6. MVP и роадмап

**MVP (3–4 мес part-time):**
- Движок симуляции + drag&drop + 10 уровней эпохи «Рим» (Цезарь, Клеопатра, Брут).
- Редактор уровней + солвер решаемости.
- Историческая справка после уровня.
- Без монетизации — TestFlight, собрать фидбек по fun-фактору. Это главный риск проекта: механика Storyteller обманчиво простая, «магия» в дизайне правил.

**v1.0 (+2–3 мес):** 2 эпохи (~35 уровней), подсказки + rewarded, IAP «полная игра», локализация EN/PL/RU, релиз App Store + Google Play.

**Дальше:** эпохи раз в 1–2 мес (Addressables, без релизов), ежедневная головоломка, подписка, питч в Apple Arcade.

## 7. Риски

- **Геймдизайн правил** — главный риск. Storyteller делался годами именно из-за тюнинга движка историй. Митигировать: маленький набор ортогональных правил (любовь, смерть, предательство, власть, ревность), расширять медленно.
- **Сравнение со Storyteller** («клон») — отстраиваться артом, историчностью, справками.
- **Историческая критика** — плашки факт/легенда, консультация с историком на этапе текстов.
- **Дискаверабилити** — без UA-бюджета рассчитывать на ASO («history puzzle»), фичеринг (образовательность!), TikTok/Shorts с геймплеем «собери убийство Цезаря».
